# CS223 Digital Design Labs

This repository contains lab assignments from CS-223 course, covering digital logic design concepts and system implementation.

## Labs Overview

### Lab 1 – Digital Building Blocks
Implementation of decoders and multiplexers.

### Lab 2 – Multifunction Register & 7-Segment Display
Design of a register system with display output.

### Lab 3 – Smart Parking Management System
A system-level digital design project simulating parking control logic.
